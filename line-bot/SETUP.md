## ステップ1. LINE公式アカウント開設（10分・無料）

1. **LINE for Business** にアクセス: https://www.linebiz.com/jp/entry/
2. 「LINE公式アカウントをはじめる」→「無料でアカウントを作成」
3. LINE Business ID（殿の個人LINEで作成可）でログイン
4. アカウント情報入力:
   - **アカウント名**: `1万円払った1000人` または `THE THOUSAND`
   - **業種**: 個人 → コミュニティ・サークル
   - **メアド**: `imai@telewor.com`
5. 規約同意 → 開設完了
6. **LINE公式アカウント Manager** に自動遷移: https://manager.line.biz/

✅ ここまでで「LINE友だち追加URL」が発行される（`https://lin.ee/xxxxx` 形式）→ THE THOUSAND サイトの PAY セクション直後に貼る用

## ステップ2. Messaging API チャネル開設（10分・無料）

1. **LINE Developers Console** にアクセス: https://developers.line.biz/console/
2. 同じ LINE Business ID でログイン
3. 「**プロバイダー作成**」→ 名称: `RYOSEIWORLD` （会社名でOK）
4. 作成したプロバイダーを開く → 「**新規チャネル作成**」→ **Messaging API** を選択
5. 入力:
   - **チャネル名**: `THE THOUSAND Bot`
   - **チャネル説明**: `1万円払った1000人コミュニティの自動応答Bot`
   - **大業種**: 個人 / **小業種**: 個人（その他）
   - **メアド**: `imai@telewor.com`
6. 規約同意 → チャネル作成完了

---

## ステップ3. アクセストークン発行（5分）

1. 作成したチャネルを開く → 「**Messaging API設定**」タブ
2. ページ下部「**チャネルアクセストークン（長期）**」→ **発行** ボタン
3. 発行された長いトークン文字列をコピー（**これが家来に渡す値その1**）
4. 「**基本設定**」タブに戻る → **チャネルシークレット** をコピー（**家来に渡す値その2**）

---

## ステップ4. Webhook 有効化（5分・後で家来が URL を入れる）

1. 「Messaging API設定」タブの「**Webhook設定**」
2. **Webhookの利用** → **オン** に切替
3. Webhook URL欄は **空のままでOK**（家来が Cloudflare Workers デプロイ後に貼る）
4. 「応答メッセージ」「あいさつメッセージ」**両方OFF**（Botが全部処理するので干渉防止）

---

## ステップ5. 友だち追加リンク取得（2分）

1. **LINE公式アカウント Manager** (https://manager.line.biz/) に戻る
2. 左メニュー「ホーム」→「**友だち追加**」→「**友だち追加ガイド**」
3. **追加用URL** (`https://lin.ee/xxxxx`) をコピー（**家来に渡す値その3**）
4. **QRコード** も画像保存推奨（サイトに貼ると入りやすい）

---

## ステップ6. オープンチャット作成（10分・任意・参加者交流用）

LINE公式アカウントは「Bot⇔個人」の1対1チャット主体。**1000人の横の交流を生むためにオープンチャット（無料・5000人上限）を別途併設**します。

1. LINE個人アプリ → 「ホーム」→ 「**OpenChat**」→ 「**作成**」
2. 入力:
   - **名前**: `1万円払った1000人 · THE THOUSAND`
   - **説明**: `信用も金もない涼晴に¥10,000払ってくれた1000人だけの集会所。`
   - **カテゴリ**: ライフスタイル / 同じ趣味
   - **検索**: **非公開**（招待URL知ってる人だけ参加可）
   - **参加方法**: **承認制**（家来がBotで承認自動化可能）
3. アイコン: THE THOUSAND サイトのトップ画像、または朱赤の単色アイコン
4. 招待URL生成 → コピー（**家来に渡す値その4**）

## 料金（再確認・常時無料）

LINE公式アカウント「**Communicationプラン**」:
- 友だち数: **無制限**
- メッセージ送信: **月200通まで無料**（追加メッセは1通約3円〜のLight/Standardプラン）
- API利用: **無制限・無料**（Webhook受信・Reply送信は通数にカウントされない）

実運用想定:
- Bot Reply（入金者個別の御礼）: 通数カウント**なし**（無料）
- Broadcast（10人到達告知など全員配信）: 1回 = 友だち数 通とカウント
  - 例: 100人友だち時に告知1回 → 100通消費
- **月200通の無料枠内で Broadcast 月1〜2回までは無料運用可能**
- 1000人到達後に「Light Plan ¥5,000/月（5,000通付き）」へ昇格すれば余裕

→ THE THOUSAND の運営想定では **完成形(1000人)まで月¥5,000以下で完全自動化** 可能。
